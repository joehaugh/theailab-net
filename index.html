Frontiers in AI

A hands-on study of the AI frontier as it stands in late 2026: AI software engineering — configuring, extending, and orchestrating autonomous coding agents through a professional software development lifecycle.

You build this competency through four mini-projects that stack on each other — your own development environment, agent configuration and custom Skills, agent harness and hook engineering, and a spec-driven SDLC capstone — before applying the whole toolchain to an original interdisciplinary research project. Running alongside the technical work is a discussion of what happens, to labor, to ethics, to what we can know, when agentic systems replace or augment knowledge work.

The arc

Four mini-projects, then a research project

MP1 · Weeks 1–2
Development Environment

Configure a professional, reproducible shell and terminal for agentic software engineering, with sound secrets hygiene from day one.

MP2 · Weeks 3–5
Agent & Skills Configuration

Package reusable Claude Code customizations — Skills, slash commands, subagents — into a small plugin a classmate can install.

MP3 · Weeks 6–9
Harness & Hooks

Wire lifecycle hooks so the agent formats, logs, injects repo state, and blocks dangerous commands whether or not the model “remembers” the rules.

MP4 · Weeks 10–13
SDLC Capstone

Take a real web application from ideation to MVP through a full spec-driven lifecycle: plan, decompose, implement, test, review, deploy.

Weeks 14–15 are given over to an original interdisciplinary Final Project and its research-poster presentation.
